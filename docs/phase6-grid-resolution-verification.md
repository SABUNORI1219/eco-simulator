# eco-simulator: secondsToTransfer離散パターンの原因切り分け（探索格子解像度依存の検証）

**タスク1（前回完了）の続き。** ランダム間隔・固定間隔いずれも、一様分布から極めて有意に
乖離した離散クラスタ（34s/54s/16s/45s/27s/7s等）を示した。エイリアシング（ポーリング周期との
干渉）は排除できたと判断できるが、**このクラスタが「ゲーム側の本当の更新間隔」なのか
「f探索アルゴリズム自体の格子解像度（粗探索の分割数）が生んだ人工的な離散化」なのかは、
まだ切り分けられていない。** 今回はこれを検証する。

## 実施方法

**前回と同じくブラウザ不要、Node.jsから直接API。前回の`scratchpad/phase6/`の
収集・分析スクリプトをそのまま拡張して使うこと（作り直さない）。**

### データ収集（今回は1パターンのみでよい）

**エイリアシングの有無は前回決着済みのため、今回は固定間隔パターンを再度行う必要はない。**
ランダム間隔（45〜165秒）のみで実施する。

`estimateGlobalTransferPhase()`の粗探索の分割数（現行値をコードから確認し、報告に明記すること）
を、**現行の約2倍**に上げた版を用意する（3倍等の大幅な変更は避ける。理由は後述の懸念参照）。
このとき、粗探索が2段階（粗→細）のどちらの分割数を指しているか、両方なのかを明確にし、
変更箇所を報告に含めること。**本番の`eco-logic.js`は変更せず、検証用に複製した関数で行うこと。**

この高解像度版で、前回と同じ手順（ランダム45〜165秒間隔）で**150〜200回分**収集する
（目安3〜5時間）。

### 懸念事項（着手前に必ず確認すること）

前回、固定間隔180件中34件（約19%）で90秒のWorkerタイムアウトに接近・超過していた
（低fのときに候補空間が爆発的に増えるため）。**格子解像度を上げると計算量が増え、
タイムアウト率がさらに悪化する可能性が高い。** 収集開始前に数回試し打ちし、
タイムアウト率が前回から大きく悪化していないか（目安: 30%を超えないか）を確認すること。
悪化する場合は、解像度の上げ幅を控えめにする、またはタイムアウト自体を1つのデータ点として
記録した上で除外して集計する、のいずれかで対応し、対応内容を報告に含めること。

### 副次検証の領地選定（自動化）

前回の7領地候補（Winding Waters / Path to Ahmsord / Heart of Decay / Ogre Den /
Dreary Docks / Ragni North Entrance / Festival Grounds、Dreary Docksはbrust確認済みで
除外済み）に加えて、**現在稼働中の全所有領地をスキャンし、Trio A
（Efficient Resources/Resource Rate/Larger Resource Storage）ボーナスが検出されない
領地を自動的に洗い出し、候補に加えること。** 手動での見立てより確実なため。
最終的に使った領地の一覧（自動検出分含む）を報告に明記すること。

### 分析・出力

1. 今回（高解像度）のヒストグラムを、**前回（現行解像度）のランダム間隔パターンの
   ヒストグラムと並べて比較**する。単独の新規分析ではなく、必ず前回データとの比較として示すこと。
2. クラスタの位置（34s/54s/16s/45s/27s/7s等）が、解像度を上げても同じ場所に留まるか、
   ズレる・増える・分裂するかを確認する。
3. 判定基準:
   - **クラスタの位置がほぼ変わらない** → 探索格子の解像度が原因ではない可能性が高まる
     （ゲーム側の本物の仕様である可能性がより強く支持される）
   - **クラスタが移動する、またはより細かく分裂する** → 探索格子の解像度に依存していた
     ことになり、「アルゴリズム由来の人工的な離散化」だった可能性が高い
4. 副次検証（エメラルドチャンネルのadmissible区間）が、今回のクラスタとも整合するかを
   前回同様に確認し、**今回は結果を明示的に報告に含めること**（前回の最終報告では
   この部分の結論が明記されていなかったため）。

## 全般の注意

- 本番コード（`eco-logic.js`/`script.js`）は一切変更しない。検証用に複製した関数のみで行う。
- ゲーム内の実際の運用・挙動についての推測は書かないこと。
- 「ゲーム側の本当の仕様かアルゴリズム由来か」について、今回のデータで判別できない場合は、
  無理に結論を出さず「切り分け不可能だった」とそのまま報告すること。
